# Frozen DietPal coursework source

This branch preserves 167 selected historical source/artwork files from the undergraduate project. One embedded recipe API credential is redacted. Private academic submissions, IDE/build caches and machine configuration are excluded. The source files otherwise retain their captured bytes; SHA-256 values and the redaction marker are in ARCHIVE_MANIFEST.json.

This archival source is not the repaired runnable edition. Use [Original or Flagship on main](https://github.com/ahmad-527/dietpal-android) for current builds, instructions, validation and downloadable APKs. New documentation, Git attributes and the Gradle licence accompany the selected snapshot; they are not represented as original coursework files.
